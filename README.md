
# Python Data Analysis Application

## Project Overview
This project performs data analysis using Python libraries such as NumPy and Pandas. It also includes data visualization and REST API integration.

## Features
- Dataset loading using Pandas
- Data cleaning and manipulation
- Statistical analysis using NumPy
- Data visualization using Matplotlib
- REST API integration
- JSON data processing
- Report generation

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Requests
- REST API

## Project Structure
- main.py
- requirements.txt
- README.md

## How to Run
1. Install the required libraries.
2. Run main.py.
3. View the analysis results and generated report.

## Output
The application displays student data, average marks, highest marks, lowest marks and API data.
It also generates a graph and report.
